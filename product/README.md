# 磁吸直升机风扇台灯

## 产品与外观
用于宿舍床架下书桌、低天花板阁楼。严格依用户图片保留天蓝色圆鼓机身、细长渐缩尾梁、尾翼、尾部装饰桨、白色双滑橇、顶部吊杆及圆形吸顶座。主旋翼四叶纯白，去掉桨尖装饰色。机身、尾梁与尾翼统一天蓝色，默认色值#87CEEB。垂直尾翼以尾梁中心轴上下严格对称；左侧白色三叶尾桨采用窄根、外端宽圆的桨叶，一叶朝上、两叶向下展开。右侧尾尖设水平配平翼，与半边垂直尾翼同形同尺寸，一体打印。小尾桨沿尾梁后移以便视觉居中，默认后移1.5mm。双侧圆窗为比机身更浅的不透明浅蓝色，默认#C9EAF8，中心按钮同色，独立窗框保持白色。圆窗由独立覆盖式窗框、固定窗面和小型中心按键组成；窗框可银灰或白色，默认采用白色PETG，沿球面贴合并覆盖浅蓝窗面边缘，圆形按键延续窗面曲率，以细缝留出运动间隙，分别标记灯泡及四叶风扇图标。

机身前面与底部为半透明打印透光件。灯与风扇共用电池，独立驱动与控制，可同时开启。尾梁下方设置USB-C，充电开口中心相对原位置向上10mm，位于尾梁下方后侧球面，默认从后侧插入。

## 磁吸安装
用户指定圆片磁铁直径30mm、厚2mm、外露约0.5mm，对应名义埋深1.5mm。初始槽径默认30.3mm，薄胶固定，胶层会占用深度，实物装配时控制露出量。磁铁尺寸不能证明承载，需在实际钢架及涂层上验证整机重量、振动与吸附稳定性。

## 造型尺寸与结构
用户授权整体线性放大1.25倍，并将机头至尾端上限放宽为约250mm；预计含装饰尾桨约244.7mm，不把主旋翼扫掠算作机身前后长度。球形座舱直径100mm，前透光口约59.5mm，底部在Z=-36.25mm切平、透光孔直径63.75mm。四叶主旋翼直径250mm，最宽37.5mm，桨叶厚度仍按用户要求保持1.6mm。磁铁仍为Ø30×2mm，槽深1.5mm；两侧按钮仍为Ø12mm。
窗体带弧面承靠台阶，台阶落在机身浅槽内，由内部压环和螺钉夹紧；另覆独立白色窗框，不用装饰窗框代替受力台阶。尾梁为实心渐缩体，圆形肩面承靠机身，Ø16mm短圆柱插头长4mm，略大于2.4mm壳厚；两颗轴向螺钉从内部锁紧，后方仅露圆形尾梁。起落架根部有定位销和贴合球壳的曲面承肩，内部曲面压帽锁紧。
滑橇长90mm，轨中心Y=±56.25mm、Z=-51.25mm；前后支杆位于X=±22.5mm，球心下25mm以连续弧线向外下方伸出，前后对称。尾翼总高50mm，上下关于Z=-3.75mm镜像；右配平翼复用半片尾翼，左侧三叶装饰桨保持参考图外形。
机身、尾梁及尾翼保持天蓝色，窗面与按钮浅蓝，窗框、滑橇和旋翼纯白。内部布局及固定件不得形成额外外露孔洞或凸台。只保留功能性的透光面、圆窗、旋翼轴通道和尾根下方USB-C口，以及检修接缝。
固定吊杆承重，主旋翼经两只6800轴承转动，尾桨固定装饰。默认Pololu3060、5:1 HPCB6V无编码器减速电机，单节电池直接供电，3mm D轴驱动内部O形圈，以3.75:1再减速；总减速18.73125:1。首样PWM默认60%，电机持续绕组电流验收上限0.375A；转速、风量和噪声须实测。DRV8213RTER提供限流与堵转后锁存停机，不新增外部开口。用户选择3200mAh单节18650；选定远阳FLY.18650.3200.3C，裸电芯最大Ø18.6×65.2mm、46g。由供应商点焊引线，配连接板电池保护，预留Ø19×66.2mm横向空间，不直接焊接电芯。照明用于独立读写，4000K为默认色温，Ra≥80；光源、恒流驱动与内部散热按读写照度重新匹配，不固定灯板20mm或平均0.5W。无额外外壳通风孔，外观和原透光面保持。温升、照度和风量以原型验证。
左控灯、右控风扇；短按开关、上电默认关闭；检测到USB VBUS时由固件关闭两负载；拔线稳定500ms后仍保持关闭，需要重新按键，不提供硬件电源隔离。USB-C位于尾根下方后侧球面，从后侧插入，XIAO用可拆卡座固定。现成元件和紧固件不随外壳放大。

## 平台与装配选择
基板暂选Seeed Studio XIAO ESP32C3（seeed/xiao-esp32c3），官方尺寸21×17.8mm，有USB-C、1S电池充电及独立控制引脚，无线功能默认关闭。已比较Atomic Battery Base，其200mAh内置电池不适合本方案容量目标。Grove - Mini I2C Motor Driver v1.0（seeed/grove-mini-i2c-motor-driver-v1-0）默认限流200mA，尚未证明适合旋翼电机，不选定。LED Driver Board for XIAO主要面向可编程灯带，本产品优先白光照明，未选定该扩展板。

用户已选择小型连接板，承载两个按钮接口及灯、风扇的独立驱动，减少散线和内部固定支架；基板仍为XIAO。这一选择授权小板设计；当时100–250元及约一周为初始估算，当前六层板与双面装配须重新询价。两侧按键通过短线束连接，避免让主板横贯机身。

## 风扇动力默认值与依据
250mm四叶旋翼保留12°桨距、37.5mm最大弦宽及1.6mm厚度，外形和颜色不改。默认32×1.5mm、70A EPDM O形圈，中心距23mm，有效轮径30/8mm，工作中性线长111.059mm、名义拉伸5.53%。电机以两颗M1.6×3固定在2mm内置端板上，孔位预留±0.3mm隐藏张紧调节，D轴皮带轮以小量适用PETG及钢材的双组分环氧胶作轴向点固。
采用厂家6V曲线端点并外推单节电池工况，BEM叶素模型含低雷诺数阻力、轴承及皮带损失和近顶壁敏感性。60%PWM下名义转速约411–514rpm，绕组电流约0.26–0.30A；全负载假设范围更宽，不作为实测风量或温升承诺。首样按20kHz驱动/制动PWM，D3驱动IN1（高电平40%，低电平60%），D5使能IN2；关闭时两脚均为低电平。相对原7线控制束增加内部D5/地线对，不增加外部开口。从顶部看逆时针旋转，确认向下送风；关闭至少10ms再开启可复位堵转锁存。限流阈值随电池变化：3.3V约0.413A、4.2V约0.525A；约3.055s启动忽略窗口之后，达到阈值触发关断。该阈值并非持续运行电流额定值。PWM控制不具备恒转速功能；电池压降会降低风速。
依据：Pololu3060产品页 https://www.pololu.com/product/3060 及2026年Rev6.2手册；厂家说明6V空载转速6500rpm±20%、空载电流170mA±50%，堵转数据为理论外推，建议持续电流不超过额定堵转电流的25%。TI DRV8213资料 https://www.ti.com.cn/cn/lit/ds/symlink/drv8213.pdf 。

## 控制程序
XIAO ESP32C3程序适配DRV8213、TPS61500、ADS1115及三只NTC：独立按键、上电关闭、风扇20kHz反相PWM，灯EN连续高50ms启动后5kHz模拟调光。三路温度按60/70℃、43/48℃、40/45℃开始减光/关闭；探头/ADC异常和电池低压关闭两路，恢复需重新按键。I²C使用D7/GPIO20 SDA、D6/GPIO21 SCL。控制默认及烧录说明见产品固件资料；软件只能关闭负载，不能停止XIAO原板充电。实际波形、带载电流、探头校准、封壳温升和读写照度仍须实测。

## 读写照明验收目标
工程默认：底部透光面距桌面300mm，400×300mm读写区平均照度至少500lx、最低至少300lx、最大/最小照度比不超过3；默认4000K、Ra至少80。用最终打印透光件进行照度网格、反光及温升测试，不把灯珠目录流明或估算当整灯通过。不要求用户按固定灯板尺寸寻找商品，具体光源与配套驱动由设计选型。GB/T9473-2022是读写台灯参考标准，现行状态见https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=01E8CB5816342FEF982F809103554FA0；上述矩形区域和安装高度是本项目工程默认，不宣称标准等级认证。

## 阅读灯运行与散热默认值
灯源名义约267mA，公差计算257–276mA；其14–18V是COB串的电压，不从XIAO的3.3V脚供电。灯扇由保护后电池独立分支供电。原型默认灯源60℃开始降功率、70℃关闭，外壳热点43℃开始降功率、48℃关闭，电池40℃开始降功率、45℃关闭；温度采集故障或电池低于3.3V关闭两路，恢复后须重新按键。以持续工作达到热稳定时的照度作为验收，若降功率使读写区不达标，应继续改内部导热或光路，不降低照度目标。

按约4W灯源、升压效率80–85%和保守可用容量估算，灯单开约1.5–2小时、灯扇同时约1.2–1.6小时；XIAO约380mA充电预计9–11小时，均需实测。保持充电时灯扇关闭。电池保护芯片BQ29700DSER、并联背靠背CSD85301Q2及4A熔断器位于连接板；XIAO电池端和负载全部接保护后侧。磁铁规格不变，整机重量增加后重新验证实际床架上的吸附与振动。

## 自行制作与最少装配
用户自己设计、自己组装，不采用厂家整机或上下总成预装。简化必须体现在实体零件和装配动作上，不把工作转移给厂家算作减件。反光罩与两只耐温ASA支座合成一件，取消两处胶接；XIAO卡座集成板厚承托，取消独立适配垫片；电池使用一条25mm无扣魔术贴替代两条10mm绑带，并扩宽托座带槽。此处尺寸为工程默认。
电池托座保持可拆，主托架与电池座不能在原开口下直接合为一体而牺牲装入通道。承重连接、轴承轴向定位、旋翼减速、独立按键、读写照明热路、电池保护和三路温控仍承担功能，不以删除这些零件代替简化。PCB焊接、线束制作、烧录、温度校准与首样测试均由用户自行完成；电芯使用有点焊引线的规格，不在裸电芯上直接焊接。现有六层双面PCB及15件定制铝件仍是自行制作的主要复杂度，尚不能称为极简手工项目。
