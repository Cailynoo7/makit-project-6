# 磁吸直升机风扇台灯

用途：床架下或低天花板的磁吸充电风扇阅读灯。由用户自行制作、接线、烧录和组装，无厂家预装。保持已确认外观：天蓝球形机身#87CEEB、浅蓝不透明窗面与按钮#C9EAF8、白色窗框/旋翼/吊杆/起落架，前、底透光口不新增外露孔。

## 外形与接口
座舱Ø100mm，鼻尾总长约244.66mm，主旋翼Ø250mm、弦宽37.5mm、叶片厚1.6mm。机头-X、尾部+X、左右±Y、顶部+Z。前口切面X=-40.1875mm；底片Ø63.75×1.2mm、Z=-36.25。左右按钮Ø12mm；白框外径43.75mm，曲面薄胶0.15mm只作装饰，不承担结构载荷。
尾梁圆肩X=47.5，短定位头Ø16×4mm、单边间隙0.2mm，内置防转平面，一颗固定侧M2×5内锁。左右滑橇根部X=±22.5、Z=-25，轨径3.75、轨中心Y=±56.25/Z=-51.25；四处曲面压帽各用M2×8锁紧。不得把外露接头改成矩形。
磁铁Ø30×2，槽Ø30.3×1.5，计入薄胶后约外露0.5mm。承重链保留M4×90沉头螺栓、吊杆、固定轴和6800轴承，不以卡扣替代。

## 左右分壳与内架
沿Y=0分为负Y固定壳和正Y可拆壳。两个M2×8锁点在前上[X=-35,Z=12]和后下[X=21.5,Z=-32.2]，轴均沿Y；头部压住活动壳3mm通孔耳，固定壳5mm接收座提供4mm啮合，夹紧力沿-Y使Y=0承靠面贴合。打印螺钉连接方案生成局部导孔/承靠结构，无新增螺母、嵌件或独立定位销。前耳与后耳分别经现有前口和底口操作，必须取下两片透光片。
后部一体舌槽来自分件连接方案：内侧X=37.5、Z=18，舌高6mm、根部高9mm，伸出6mm、槽深6.5mm，单边间隙0.2mm，导入端0.5mm倒角。定位结构先约束X/Z错位，两颗螺钉负责闭缝；不能用螺钉硬拉明显错位的壳。尾头仍须预先对正，柔性窗支线需扶住插壳后再合壳。
固定半壳独立承担16mm宽、5mm厚承重横梁和M4螺母座，活动半壳不夹在承重连接中。壳内最小外皮1.2mm，不增加外露螺丝刀孔；前/底片在试装和内部螺钉锁紧后才装。前口内侧增加半径27mm、深1.2mm的操作导入口，外口尺寸不变。
一体PETG内架包含主板/电机支承、电池鞍座、XIAO承托和开放线束导向。一个前定位销与一颗后侧水平M2×6固定内架；不能再安装旧独立托座、卡座、粘接线束夹、两条托座扎带或两颗卡座螺钉。
主板为40×50mm完整76器件模型，两颗M2×4固定。F1底避让8.1×4.7mm、底Z=-7.5、补强底Z=-9.2，余厚1.7mm；左安装台焊点避让保留。导线不从主板焊点与机架之间强行穿过。

## 电池与充电
电芯FLY.18650.3200.3C（C5289740），裸芯上限Ø18.6×65.2；含点焊引线和绝缘包覆的检查包络Ø19×66.2，轴沿Y、中心[0,0,-24]。禁止直接在电芯端面焊接，不用约70mm长的保护电池替换。
鞍座孔Ø19.6，两处承靠站Y=±7；单条25mm宽、单层≤0.8mm的无扣魔术贴嵌入26mm槽，底面不叠层、只在顶部搭接。端挡Y=±36.4/Z=-21，两块7×3mm绝缘缓冲垫由3mm压到2.3mm，端子中心留空。可拆端挡两颗M2×6，不永久胶死电池。换芯在壳外进行：拆两颗端挡螺钉，松绑带、释放探头及引线，端挡和电芯分别沿+Y直向抽出；无需抬升端挡或拆主板/热桥。
USB-C后口中心[42.5551,0,-26.25]，从+X水平插入，小口9.7×4.0、插头凹位13.3×7.3、R0.5、名义凹深4.75mm。XIAO水平安装；1.9mm槽按1.6mm实板加0.3mm间隙。社区STEP板厚1.0mm需要0.6mm集成承托；实际1.6mm板将承托高度改为0，先做USB局部试件。社区模型不能代替实物板厚和插合验证。局部试件的两颗M1.6×5仅用于试件，整机XIAO无独立卡座螺钉；壳外从+X侧滑入，以一处可剥离绝缘胶带止退，检修揭带后向+X退出，电池可保留。

## 一体散热桥与光学
取消六片独立均热片、四只接触座、两根上部连接件、左右分离桥及旧桥根/接触螺钉。光源承台、左右导热支路和贴壳接触面为一个连续金属件，只用两颗M1.6×5固定到ASA支座；不允许塑料打印热桥。
COB为HL-LM002H384W-5B2C5(Ra2)(ANSI-4000K)，包络13.8×13.8×1.8mm，中心X=-28、光面向下，12×12×0.15mm电气绝缘导热胶连接18×34×3mm光源平台，胶不覆盖光面和焊盘。哑白ASA反光罩与两只支座一体打印，两颗M1.6×4固定到内架；罩壁1.6mm、上口Z=-4、下口Z=-25.5，保留16×2mm前混光口及25°遮光片。
金属默认1050/1060导热铝，一件制造，不按旧AL01–15图加工。薄接触面需要加工/成形工艺与报价确认；整体STEP和铝件加工说明是当前规格。线侧棱边倒钝0.10–0.20mm。一般线性±0.10、孔位±0.05、接触面尺寸±0.05、平面度0.05mm；向少材料侧允许0.10mm，不得向装配间隙侵入。新热桥无旧接触座攻牙孔。
COB绝缘胶k≥1.5W/mK、贴壳非固化绝缘填料k≥3W/mK，薄层填满接触面，不塞厚垫。可拆壳与金属之间不能永久胶死。不能根据实体连续性或接触面积宣称散热合格；300mm处400×300mm区域平均≥500lx、最低≥300lx及均匀度≤3的要求不降低。

## 温控与线束
三只HNTC-103F3950FB-100P珠头按Ø2.8×7.5mm检查，分别测COB、壳体和电芯，全部保留。电芯探头[11,-18,-24]；COB探头避开光面和焊盘；SHELL探头固定在热桥贴壳面的内侧，以绝缘导热胶填实名义约0.3mm胶隙，不粘活动半壳；装机后需实测校准与外壳热点的温差，不能把空气中悬空探头当作壳温。电芯探头采用可移除固定，换芯先释放。
主板普通母壳总高≤14mm：2P横截面≤5.6×3、7P≤3×18.3、3P≤8.1×3；窗端采用低型焊线1×2母座，含焊线/热缩总深≤11.5mm、横截面≤3×5.6mm。三路NTC用TE1375820-2/1375819-1及26AWG转接线，原线径不明不可直接压接。转接焊点错开≥8mm、热缩后单接头≤1.8mm、双线束≤3.4mm。
主控束Ø6检修弯与12根XIAO焊盘扇出保留；主线按布线表铺设、逐线导通/极性检查，切勿用导线吊挂组件。COB/壳体/电芯探头成品毛坯总长125/80/105mm，包含珠头和插壳，按定型路径修整。常规弯曲R6，个别固定末端见裁线资料，不在接头根部硬折。主束开放导向并入内架，用一条2.5×100扎带闭合，不再粘接独立夹。
所有电池/NTC/线束/插壳和COB参考体均不打印。

## 电机与承重
Pololu3060 5:1 HPCB6V无编码器电机采用厂家STEP，轴X=23、齿轮箱前面Z=29.3，两颗M1.6×3穿过2mm端板进入金属牙1mm；Ø6支柱保留。2.4×1.8mm长孔允许±0.3mm张紧微调。
3mm D轴小轮有效Ø8，主轮有效Ø30，中心距23，32×1.5mm EPDM70A O形圈位于Z=35.3，名义伸长5.526%、包角122.86°，总减速18.73125:1。D孔先试配，不敲轴；小轮微量环氧轴向点固，不让胶进入轴套，先调张力再点胶。电机与小轮成组检修。
两只6800轴承10×19×5，内圈承肩Ø12.6；内隔套Ø12.6/10.2×7.9，外隔套Ø19/16×7.9。上压肩底Z=59、固定轴顶Z=58.8，保留0.2mm间隙；薄固持胶仅用于外圈/毂，不进滚道、内圈。M4承重连接正常检修不拆散。
固件保留独立灯扇、USB存在时两路关闭、拔线不自动恢复、三路NTC/电池保护；首样电机60%PWM，绕组RMS≤0.375A必须实测。历史程序编译/主机测试不证明实际负载、波形或温升。通用N20不可仅凭外形替代。

## Making and assembly
PETG塑料默认0.4mm喷嘴、0.2mm层高；一体光学支座为哑白ASA，同样层高。内架先以主板平台方向规划打印，鞍座余壁约1.25mm，至少三条连续周线；弧形支杆、侧孔、卡槽与桥筋用局部支撑，去支撑不扩大配合孔。压环后平面朝平台，支撑尽量接触内面，按钮限位径向0.8mm处保持两条连续挤出线。
左右壳接缝面朝平台，检查悬挑支撑与内侧螺钉导孔；先打印接缝、窗肩、短尾头、起落架根部和USB试片。250mm旋翼需要可用尺寸大于250mm的平台或打印服务，不能按壳体分件规划当作已适配小平台。
先在壳外装电池、板、电机、光学/热桥和线束，再准备两半壳附件，内架侧装并用一颗螺钉固定；接可拆侧窗支线、合壳并锁两颗螺钉，最后装前/底片。完整逐项顺序以装配说明为准，说明卡里多个轴承/螺钉动作不能算成一个实际动作。
深检先撤下整灯、断USB、关灯扇，取下前、底透光片并拔J2，分别经前口和底口卸两颗M2×8，先沿+Y退出8.5mm，再向机头/下方拿出，之后侧向开壳；仅开壳不摘皮带，不动吊杆、磁铁或轴承。取整架时再解除皮带；先断可拆侧按键支线，支撑内架再卸唯一固定螺钉。固定侧按键支线释放、其余柔性支线停放后整架侧向取出，SHELL探头随热桥，后续都在壳外操作。夹插壳不拉线，不带电拔升压光源。12只主板插壳在壳外均有+Z12mm直向离针空间，不能掰针。
窗肩与按钮0.15mm名义空隙、0.45mm总行程、0.30mm开关压下量保留；实物须无预压、可触发且能回弹。禁止盲目加行程或削开关。前透光件可剥离点胶；底片仅点胶到负Y固定半壳，不能跨接粘死活动半壳，白框0.15mm曲面薄胶；磁铁按薄胶后的外露高度确认。

## 结构检查结果
当前两颗锁壳螺钉的轴向已从X改为Y。侧壳、整架、热桥、主板、电池端挡、电芯、控制板、内架螺钉、随内架紧固件以及两颗锁壳螺钉分别退出，共11组规定路径无相交；采样步长0.5mm、网格公差0.02mm。两片透光片均先拆，柔性线束按前提断开、释放、扶住插壳并停放，不把刚性线束图当成自动随动的实物。
前上与后下螺钉分别从前口和底口操作。使用Wera950PKLS05022040001标准1.5mm超短臂内六角扳手，厂家标注长臂90mm、短臂4.5mm；实际螺钉先手工带正螺纹，分次转动，脱牙后手工拿出。前锁点按指向机头的155°至215°范围分次转动，后锁点按指向底口的195°至255°范围分次转动。含5mm螺纹退出和1.2mm脱开换位的工具包络无相交，最小名义间隙前0.438mm、后0.962mm；轴径1.8mm及弯头范围4.5mm为工程检查上限，厂家未提供弯曲半径。工具包络检查结果见本次锁壳连接核对，不能将工具包络替代实际手部操作或紧固扭矩试验。
独立结构件与紧固件相对1ed13b5减少30件，本次仍是两颗锁壳螺钉，无新增独立连接件；45张说明卡不能当作实际手工动作计数，没有计时装配实测。均热片仍已删除。热桥是一个复杂定制金属件，制造可达性、薄壁变形和报价仍须确认。
