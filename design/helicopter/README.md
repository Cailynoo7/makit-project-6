# 磁吸直升机风扇台灯

用途：宿舍床架下和低天花板空间的磁吸充电灯。外观依据用户参考图：正圆俯视的球形座舱、细长圆锥尾梁、上下镜像尾翼、左装饰尾桨与右半片配平翼、平滑弧形支杆与前后对称双滑橇。天蓝机身#87CEEB，浅蓝不透明窗面及按钮#C9EAF8，白色窗框、滑橇、吊杆和旋翼。

## 外形与尺寸
用户授权整体线性放大1.25倍，机头至尾端上限约250mm。座舱Ø100mm；主旋翼Ø250mm、弦宽37.5mm，依先前要求桨叶厚度仍为1.6mm。前透光口约Ø59.5mm、切面X=-40.1875mm；底透光片Ø63.75×1.2mm，水平面Z=-36.25mm。左右按钮仍Ø12mm，与窗面共用外球面曲率。磁铁仍Ø30×2mm，顶部槽Ø30.3、深1.5mm，名义外露0.5mm。机头-X，尾梁+X，左右±Y，顶部+Z。

## 隐藏连接
圆窗定位段Ø37.5，外承肩Ø42.6；机壳圆孔Ø38，弧面承靠浅槽径43.1、深1.2。窗体承肩落在机壳上，内侧白色压环由两颗M2螺钉夹紧；独立白色覆盖框外径43.75，沿球面覆于浅蓝窗体边缘。装饰框不承担窗体固定载荷，曲面胶合不适用平面装饰板连接方案。
实心尾梁承肩位于X=47.5mm，短圆柱定位插头Ø16、长4mm，单边间隙0.2mm，插入长度略大于2.4mm壳厚。圆肩承靠机身平座，两颗轴向M2从内部锁紧；外部只露圆形渐缩尾梁，没有矩形接头或额外外露支架。尾翼高50mm，上下严格对称，右侧复用25mm半翼。左侧纯白三叶尾桨固定装饰，桨心[176.875,-4.625,13.75]。
滑橇轨径3.75、长90mm，前后支杆X=±22.5，机身根部Z=-25，轨中心Y=±56.25、Z=-51.25；弧形向外向下伸展。根部由隐藏定位销、贴球面的白色承肩与内侧曲面压帽夹持，螺钉从内部拧入，无外露螺钉头。

## 内部布局与检修
40×50mm连接板为完整76器件制造装配模型，F1避让和两处NTC导向保留。电芯为FLY.18650.3200.3C（C5289740），裸芯最大Ø18.6×65.2mm；点焊、绝缘包覆后的检查包络Ø19×66.2mm，轴沿Y、中心[0,0,-24]。不直接焊电芯，不换成约70mm长的保护电池。

电池独立托座有两处Y=±7mm鞍座、19.6mm孔径，一条25mm无扣魔术贴居中嵌入26mm宽槽内，底面不叠层，顶部搭接。端挡Y=±36.4、Z=-21；两块7×3mm绝缘泡棉由3mm压到2.3mm，终端中心留给引线。可拆端挡由X=±11.3、Y=24处两颗M2×6锁紧。两条2.5×100mm PA66扎带将托座绑在电路托架下，头部朝外、带身进入0.7mm沉槽。托座一体成型两处2mm高硬支承，保持电芯高度；四处侧向止挡与托架留X向0.3mm、Y向0.4mm间隙，扎带只负责夹紧。扎带满足配件表包络，深度检修剪断后换新。

COB为HL-LM002H384W-5B2C5(Ra2)(ANSI-4000K)，按13.8×13.8×1.8mm上限检查，中心X=-28、光面朝下。12×12×0.15mm绝缘导热胶将其贴在18×34×3mm铝集热板下，不覆盖光面和焊盘。两个白色ASA支座以M1.6×4固定到PETG托架；集热板用两颗M1.6×5固定到ASA支座。

两只可拆铝导热桥连接四只独立球面接触座；上盖另有两只导热连接件。下壳接触座通过螺钉就位，球面和铝内衬之间填0.1mm非固化绝缘导热材料，不永久胶死。上盖连接件胶合到上盖内衬，Z26/26.1下搭接面填0.1mm非固化材料，开盖时分离。六片0.5mm铝内衬体积/厚度等效面积约72.1cm²，外表面以≤0.15mm绝缘导热胶贴壳，避开窗口、接缝、起落架、USB与天线。金属件15件：集热板1、桥2、上盖连接件2、接触座4、内衬6；须加工铝件，不能塑料打印替代。

三只HNTC-103F3950FB-100P按Ø2.8×7.5mm最大图纸包络检查。COB探头中心[-36.3,0,-1.4]，靠基板侧边避开光面/焊盘；壳体探头约[32.841,29.584,10.142]，贴后部铝内衬；电芯探头[11,-18,-24]，沿Y贴侧面，以非固化导热材料和聚酰亚胺带保持，换芯可取下。实测需对照COB Ts点及外壳热点校准。电芯、COB及NTC是尺寸包络参考，不是厂商STEP，不打印这些参考体。

## Making and assembly
塑料件默认PETG、0.4mm喷嘴、0.2mm层高；两只COB支座用白色ASA，导孔按ASA生成。鞍座槽底径向余壁约1.25mm，至少三条连续周线；托架扎带座余厚1.3mm。曲面支杆、压帽、支座、导向及侧向孔用局部支撑，去支撑不扩大配合孔。先做窗肩、短尾插头、起落架根部和螺孔试片。250mm旋翼需要大于250×250mm可用平台或打印服务，不能按机壳120×120×82mm分件规划判断可打印。

铝件采用1050/1060或经核验的同等级导热铝材，机加工或钎焊后精修，线侧边去毛刺、倒钝。胶k≥1.5W/mK，非固化填料k≥3W/mK；薄层填满指定界面，不塞厚导热垫。先干装确认接触座可拆，再贴铝内衬。下壳接触座采用非固化界面，上盖连接件才胶合到内衬。

组装按下述检修顺序逆序：先机壳/尾梁/起落架/XIAO，再电池、圆窗、托架/主板/电机总成、接触座/桥、COB和上部组件。先装窗内板/压环，后从外侧插窗体/按钮/白框，最后锁窗螺钉。电池按斜置顺序装入，不竖直压入。透光件用可剥离弹性点胶，先试装测试再点胶；白框0.15mm曲面薄胶不承结构载荷。磁铁考虑薄胶后约外露0.5mm。

连接板M2×4先锁，再装电机两颗M1.6×3。D孔先校准，不敲击轴；小轮用微量适合PETG/钢的环氧作轴向点固，不让胶进入轴套，先校准张力再点胶。检修电机/小轮一起取出。轴承固持胶只接触外圈/毂，不进入内圈/滚道。承重桥、M4×90、固定轴、轴承、旋翼、隔套、毂盖、吊杆、磁座组成独立上部组件，正常检修无需拆散承重螺栓。

### 深度检修顺序
1. 撤下整灯并软垫承放，拔USB、关灯扇。拆前透光片，从前口先拔电芯J2；拆底透光片。不热插拔升压COB。
2. 卸三颗M2×10，先轻抬上部约3mm，用细塑料钩从缝隙解除O形圈与小轮的连接，再沿+Z整体取下约100mm，上盖导热件随上盖离开。
3. 释放主板J1/J3至J12和线束扎带/胶带，夹插壳不拉线；两侧窗端插座先保留，待托架移出再拔。XIAO焊线端保留，将已断开的分支暂放到尾侧/底口外，避开后续刚性拆装路径。J9先直拔约6.3mm，完全离针后+X移5mm，再上提12mm，绕过导向座，不斜掰排针。
4. 卸两颗M2×8根部螺钉及两颗M1.6×5；COB/其探头/集热板沿-X从前口移出70mm。卸两颗ASA支座M1.6×4，将两只支座和反光罩一起沿-X退出80mm；胶接面在壳外分开，不让支座单独穿过反光罩。
5. 先松开主线束导向夹扎带，侧向放出线束，剥离夹根0.2mm胶层，将导向夹沿+Z取出80mm，再卸四颗M1.6×10。两侧桥各向中心移10.4mm，再上提80mm。四只接触座可暂留；深度检修各向中心移12mm，再上提80mm。补回非固化填料，不剥已胶合的内衬。
6. 连接板保持锁在托架上，与电机一起取出总成，之后在壳外卸两颗M2×4拆板。单板另有上提3mm、向-X移90mm的路径，但不作为舱内首选维修方法。
7. 底口以约20×25×20mm绝缘软块托实电池，或手托，不能悬空剪扎带。剪两条托座扎带及两条NTC导向扎带，卸托架螺钉。托架/连接板/电机/小轮先上提1.5mm越过止挡、+Y移2mm，边上提7.5mm边向机头倾15°，再+X移4mm、-Y移0.5mm，最后上提55mm。电池留在支撑上。
8. 托架移出后，左右窗端短插座先向中心退出6.3mm再上提12mm；不能在主板仍在舱内时拔这两只插座。托住窗体，卸每侧两颗压环螺钉；窗体/按钮/白框先向外侧退出30mm，内板/压环暂留。然后内板/压环向中心移3mm、上提7mm、向中心移19mm、上提50mm。左右相同，电池可留舱内。
9. 电池托座、端挡、绑带、电芯、贴附探头一起上提30mm；绕竖直轴转90°使电芯轴到前后方向，+X移3mm；机头端抬高35°，再上提70mm。上盖、散热件、板、托架和窗模块须先拆，XIAO可留原位。
10. 卸XIAO卡座两颗M1.6×5，向机头-X移10mm，再-Z退20mm。1.9mm槽适配1.6mm板；1.0mm参考板使用可拆0.6mm集成承托，1.6mm实板不用。
11. 换芯在壳外进行：卸端挡M2×6，端挡/前泡棉上提30mm。松两条魔术贴，先取下电芯探头及胶带，再沿+Y滑出电芯80mm。用同规格点焊/包覆电芯，禁止直接焊芯。

所有插头、导线、扎带和胶层先按上述条件释放。检查针对所列刚性组及尺寸包络；不覆盖强拉、柔性线束自动跟随、打印收缩或实物插拔力。

当前内部静态检查无未声明共享体积。含反光罩/ASA组合和导向夹的21组分阶段路径以最大点步长0.5mm（窗模块0.25mm）、曲面网格公差0.02mm核对；起始承靠面和指定热界面接触不等于硬件穿透。电池整组至壳体最小网格间隙约0.50mm，仍须实物适配。
