# 阅读灯连接板

本板配合独立的XIAO ESP32C3，保持用户确认的机身、圆窗按钮、USB开口、旋翼和尾部外观。元件模型与机身内的连接板参考已更新；外壳造型和控制程序不变。

## 电路

- TPS61500PWP升压恒流，鸿利4000K COB，0.75Ω1%设置约267mA、约4W；14–18V灯源，输出过压设置约20.6V。DIMC1µF模拟调光。L1为10µH、SS3P6L整流，输入4.7µF，输出2×2.2µF/50V。R31为VIN偏置与主电感供电间的0Ω隔离参考支路。
- DRV8213RTER、Pololu3060电机分支保留反相20kHz PWM、独立使能和限流/失速锁存。20kHz IN1高占空40%对应60%驱动，关断时两输入低至少10ms。
- 3200mAh远阳18650接J2原始电芯端；4A熔断器、BQ29700DSER与五对并联背靠背CSD85301Q2保护。J12输出保护后的PACK端给XIAO充电/供电。R32把BQ的VSS、旁路和放电门极泄放引到电芯负极参考，主回流不经过此0Ω支路。
- ADS1115IDGSR使用3.3V、地址0x48；AIN0/1/2分别采样COB、机壳、电芯NTC，AIN3采样100k/100k保护侧电压分压。NTC为10k/B3950、三路独立10k上拉，1k/100nF滤波；I²C用4.7k上拉。

## 板与制造

40×50mm、1.6mm、六层FR4，外层1oz、内层2oz。内1/2/4为信号禁布的电源/地铜区，内3与外层走信号；电芯正极、原始负极、保护侧电源、MOS公共漏极分别隔离，开关节点独立。两孔Ø2.4mm仍在(-16,-11)、(16,-11)。普通走线/间距不低于0.2mm；自动信号过孔0.5/0.25mm，显式功率过孔0.6/0.3mm，熔断器前后主馈电各使用三只并联跨层过孔。

最新核查0DRC错误、0未连接项、4条非阻断警告；板厚、六层、孔径及线宽已实测读取。裸板Gerber、钻孔、制板预览已生成。制造版本：171fcced55d57308fe0ba67341bcf9a1e5120fcf6a640abfc35d908bb5440812.

76个器件均按手工或委托回流装配；JLC SMT清单为空，不代表可以直接下包焊订单。

76个器件均有STEP模型绑定，无未解析模型或方盒占位。Q3–Q7由精确型号CSD85301Q2的供应商原始封闭网格转为分面STEP（保留0.81mm高度）；U1补入TPS61500PWP供应商STEP。12组排针使用对应KiCad原生模型；实际STEP截面30根金属针与钻孔逐一同轴，最大轴心误差小于0.001mm。供应商模型鸣谢：JLCEDA/EasyEDA Official Library，https://lceda.cn/ 、https://easyeda.com/ 。

## 接线与温度控制

详细接线见本设计的接线说明。D1/GPIO3为灯按钮，D2/GPIO4为风扇按钮；D3/GPIO5风扇反相PWM、D5/GPIO7风扇使能；D4/GPIO6驱动TPS61500 EN；D10/GPIO10检测USB。I²C必须显式设置SDA20/D7、SCL21/D6，不能使用默认GPIO6/7。

新程序需实现灯5kHz模拟调光、冷启动EN连续高50ms、NTC/ADC开路短路与离线检测、低压关闭、USB接入关闭灯扇及拔线不自动恢复。原MEL7135程序不兼容此板。温度策略目标为灯源60℃降功率/70℃关闭、壳面43/48℃、电池40/45℃，故障后需重新按键恢复；尚未实施或实测。XIAO原充电器没有已建立的软件充电禁止接口，NTC负载关断不能停止充电。

## Making and assembly

断开电芯及USB后装配；按原理图和位号检查F1、D1、U1、U4与Q3–Q7极性，尤其是CSD的两个裸露漏极焊盘，均接公共漏极。先用限流电源做不装电芯的焊接和上电检查，再验证保护与负载；COB不热插拔，LED负端为FB采样回路，不是GND。

F1避让凹槽8.1×4.7mm、底面Z=-7.5mm，局部补强底Z=-9.2mm，余厚1.7mm；保险丝底部间隙0.715mm。左侧安装台同时避开R19及R16焊点，完整连接板与托架无共享体积。J10/J11旋转90°横排，排针行中心X=13.35mm、Y=5.3912/-4.9048mm，Pin1在X=12.08、Pin2在X=14.62；接口功能不变。TE1375820-2插壳和1375819-1端子采用厂商图纸包络，保守预留X6.5×Y9×Z20mm（14mm插头加6mm弯线空间）；与电机最小网格间隙0.4198mm，网格公差0.02mm。移除上部组件后沿+Z拔出12mm，0.5mm步长的精确几何采样最小间隙0.40mm。双线束按合拢外径3.4mm、弯曲半径6mm核对，上下导向座孔Ø4、壁1.5mm，用两条2.5×100mm扎带闭合。线束至电机精确最小间隙J10=2.2566mm、J11=2.1146mm，至皮带至少8.7442mm，至导向座0.3mm。仅连接板和内部托架改变，所有外观件几何比较不变。 线束为按厂商尺寸和工程余量建立的只读扫掠检查，不把探针包络冒充供应商STEP；插合力、压接拉力、打印公差需样件确认。新18650固定座、COB导热件及整组检修路径尚需后续完成，本次不认证整机可打印运行。J11路线核对到电芯侧交接点Z=-18，最终探头贴合点随电池固定座完成。

六层及双面装配需重新报价，旧100–250元估算不作新版报价。热稳定照度、续航、原型温升、保护动作和磁吸承载仍需实测。
