# XIAO充电口局部适配试件

用于先试装实际XIAO ESP32C3、焊线和USB插头。局部球壳、M1.6×5固定螺钉及开口沿用整机，不改变USB中心。PETG卡座与板厚承托一体打印，不再单独打印垫片。

## 制作与组装
默认0.4mm喷嘴、0.2mm层高。现有社区STEP参考板厚1.0mm，集成承托高度0.6mm；实际1.6mm板将承托高度设为0mm，先核板顶面和USB插合。保留D6/D7/VBUS三处R1焊线槽。螺钉、XIAO参考模型不打印。

整机与本试件使用相同卡座结构。参考板向机头滑出25mm的路径在0.5mm最大点步长、0.02mm曲面网格公差下没有穿透；实际板批次、焊线、USB包胶和打印缩率仍需此试件确认。用户自行组装，无厂家预装。
