# 充电口与XIAO局部适配试件

用途：先验证XIAO裸板固定、上移后的充电口对中及直头Type-C线缆插拔，不打印整机。试件为整机后下方球壳局部，天蓝PETG球壳与卡座、白PETG垫片。侧面敞开便于观察；保持整机球面、壁厚、开口和内部安装接口。

## 零件与来源
打印三件：局部球壳coupon_shell约25.55×46×20.25mm；卡座controller_cassette约22.95×40×6.60mm；垫片xiao_shim为20.5×17.2×0.6mm。两颗M1.6×5 ISO4762内六角机螺钉将卡座固定到球壳；孔来自与整机相同的打印螺钉连接方案，不额外攻丝，不换自攻螺钉。卡座、垫片和两颗螺钉可复用到整机。
XIAO参考模型来自社区vinjocarsales/xiao-series0.1.7，https://tscircuit.com/vinjocarsales/xiao-series/blob/assets/xiao-esp32-c3.step ，sha256 d3eb22a99dade7b2fb6ccc2ac102d9a5a5fac6c92ef4d58a8c496357b1ae3735。许可未标注，保留来源，仅作内部装配参考，不作为厂家机械认证。模型和金属螺钉不要打印。

## 尺寸基准
开口中心保持整机坐标[42.555111,0,-26.25]mm，相比原位置上移10mm；模型USB口心为[37.805111,0,-26.25]mm，沿+X从尾侧插入。口沿中心到外部口心4.75mm；小口9.7×4.0mm，包胶凹位13.3×7.3mm、R0.5。主控板模型PCB20.955×17.78×1.0mm，与官方PCB板框吻合。官方v1.3文件名义板厚1.6mm；夹槽1.9mm，对1.0mm板使用0.6mm垫片，对1.6mm板不使用垫片。接口型号和版本仍需实板确认。

## Making and assembly
默认PETG，0.4mm喷嘴、0.2mm层高；三件分开打印，垫片为三层实心平放且不用支撑。球壳使用裁切平面作为朝向基准，安装凸台和横向边缘按切片预览设置局部支撑及裙边；不要让难清理的支撑残留在USB槽或PCB夹槽。卡座平面朝打印平台，必要处局部支撑，清理毛刺后再试装。三件均小于50×50×25mm，但不指定用户打印机型号。
先固定球壳与卡座，两颗M1.6×5慢拧锁紧。先不连接电池、风扇或灯。模型所示1.0mm裸板加0.6mm垫片；1.6mm实板不加垫片。垫片放在承靠面，板从机头侧-X沿+X等高滑入，USB朝尾侧开口；不要从上方强压板上器件。若卡得过紧或板能明显晃动，先记录位置和现象，不强行扭拧。
插入准备使用的直头Type-C数据线：包胶应不顶壳、插头应完全插合，插拔不应带动卡座或让PCB弯曲。最后核对USB供电/电脑枚举。合格后再把相同配合用于整机。板上走线优先从元件侧引出，背面支承区域不能堆焊锡。

## 验证
试件与整机0e3c71b快照的对应球壳裁切区域精确双向体积差为0；卡座和垫片双向体积差也为0，未采用独立近似形状。
参考板、卡座、球壳、垫片没有共享实体体积。参考板从安装位置向-X滑出25mm无穿透，与卡座最小网格间隙约0.1304mm；路径步长0.5mm、网格公差0.02mm。卡座/板/垫片组合按-X10mm再-Z20mm从整机取出无穿透，同样精度。包胶量规12.35×6.5mm在±0.25mm横向和±0.30mm竖向四种偏差组合下推入20mm（0.5mm取样），与试件壳体精确共同体积均为0。
参考模型尺寸、打印公差、焊线和实际线缆仍需本试件实物验证；不据此宣称整机风扇、照明、散热和承载已验证。
