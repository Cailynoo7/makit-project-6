# Window button daughterboard
Two identical 14x18mm boards are used, one behind each 12mm curved button. Kinghelm KH-6X6X4.3H-STM plunger faces the window; bottom-side 1x02 header faces inward. Manufacturer drawing: 6mm square, 4.3mm total height, 0.3 +/-0.1mm travel, pads10x5.5mm outer extent. Switch A/B are one contact, C/D the other, per sheet1. Fixed window insert carries slide rails and a back stop; no hot glue on the switch actuator. Main board J_KEY_L/R each receives one daughterboard with a short two-wire female harness. Components are manual assembled.

Mechanical reference: SW1 uses a source-owned drawing-modeled conservative envelope,H4.3mm above its lead plane,diameter3.5mm actuator. This is not a manufacturer STEP; supplier copper/footprint,netlist,14x18mm outline and component placement are unchanged. Model provenance is recorded beside the source model.
